# Playmaker

Playmaker is a mobile-first netball coaching and planning PWA.

## Current features

- Team and player management stored in browser localStorage
- Interactive netball court with draggable player tokens
- Pass/lead line drawing and saved playbook
- Rotation planner for quarters or halves
- Game-day score, timer, lineup and notes
- Installable PWA shell with offline caching

This copy is deployed as a subdirectory of the `virtualhowto.github.io` GitHub Pages repository, at `/playmaker/`.
